# v1.1.1 preview / review-4 changes (local only)

- Source inspector attaches to the actual `.beatmapset-info__row` labelled Source; adds a Source row if missing. Removed Description fallback and large edit-button placement.
- Download hero row is width-constrained, leaving space for official osu! controls.
- RC topic selection hides difficulty/tier controls for general/metadata topics. Nonstandard names suggest a tier using documented SR bands **only as an estimate**, never certified RC classification.
- Discussion stats display CS/AR if supplied on a selected non-mania beatmap.
- Nearby discussion links show text excerpt when the post is already loaded, or a clear unavailable/open link if not. No fabricated post contents.
- Public osu! group badges now also scan discussion contexts while avoiding native badge duplicates. OAuth/API and DOM selectors still need live verification.
- Coach remains on while editing; if anchor is more than ~0.65 viewport above it, the panel is hidden visually (not closed), and reappears on return.
- Markdown visual parser separates punctuation and content, links, image URLs, inline/fenced code, quotes/headings/lists, strikethrough and timestamps; exact characters and font metrics preserved for caret alignment. Hidden behind a modal or when positioning uncertain.
- Gallery supports up to 24 detected images including HTML `<img src>` syntax and keeps link fallback for failed previews.
