# v1.1.1 Review 7 — local-only account and badge update

## Changes

- Official user-group badges: new `discussion_stuff/kmh_group_badges.js` builds native-style `user-group-badge` controls from publicly returned osu! API `groups` only. Preserves short name, official colour, group listing URL, ruleset icons and `is_probationary` modifier. No spoofing or private roles.
- Comment/reply badges: attaches group controls in actual `.comment__row--header` and supported discussion headers. Avoids duplicating existing native badges by group identifier. Keeps existing default group and Mapper badges unchanged.
- Connected My Discussions profile: banner/cover art (when provided by `/api/v2/me`), avatar, clickable username, public official groups, supporter state, and clearly indicated connection. No profile fields are guessed.
- Source metadata: Copy Source button now remains alongside the Source text; long Source values elide with a full-value tooltip.
- Settings OAuth: connected/disconnected states use green/red status text and white connection button labels. Expired sessions are treated as needing reconnection.
- Removed obsolete favourite-mapset wording from account Settings onboarding.

## Validation

- All JavaScript syntax checks passed.
- `manifest.json` parses, references new JS and CSS and has no missing referenced assets.
- Offline Chromium tests passed at widths 950px, 500px and 370px: BN probationary badge with mania icon, correct listing link, native Source/Copy alignment, green status and white Settings button, connected account profile, banner metadata and supporter status.
- The browser fixture uses mocked osu! API responses and placeholder image URLs. Real artwork, server groups, live OAuth, Firefox/Zen and actual osu!web DOM rerenders have not been verified.
- The supplied `osu_local_staff_ui_preview_v2` is a fictional local UI mock; its privileges and role mock are **not** used for account data or badge assertions.
