# osu! Modding Helper v1.1.1 — Local Fix Confirmation Log

**Build status:** local preview, NOT published or committed to GitHub.

## Changes requested and implemented

1. **Metadata inspector:** the small search/magnifier button is attached to a visible Source heading in the metadata sidebar instead of the Description content. It stays beside Source, not over its artwork. If the heading cannot be reliably located, the icon is omitted rather than placed arbitrarily.
2. **Download:** the native Download control remains. The small + menu contains official / no-video, mirror full / no-video, Nerinyan website, cover image and copy/export/read `.osu` metadata. Full background, MP3 preview, media-only and local `.osz` extraction controls and underlying reader were removed. Mirror URLs are not guaranteed to work for all sets.
3. **My Discussions images:** parses distinct image links from loaded starting and reply texts (Markdown / BBCode / supported direct links), presents four compact thumbnails by default with a +N expander for the rest (up to 16), and retains a clickable fallback when a host blocks embedding. This cannot display replies never returned by the API.
4. **Coach popover:** width restricted to 360px, positioned to the right when there is room, remains open on scroll or outside click while typing, and dismisses intentionally through its X, toolbar toggle, or Escape.
5. **Discussion buttons:** Note/Praise/Suggestion/Problem colours apply immediately via stylesheet to native `data-type` controls; no periodic JS recolouring.
6. **Ranking Criteria / SR:** selects the current difficulty from the discussion URL or selected beatmap element when possible; shows the name and SR and allows an explicit map and RC-tier override. SR is not treated as an official difficulty-tier boundary; unrecognised names show Unclassified rather than a fabricated category.
7. **Markdown source overlay:** keeps native text visible whenever its mirror is offscreen, empty, too long or out of geometry sync. This addresses floating text in the tested fixture but live React layout behaviour remains unverified.
