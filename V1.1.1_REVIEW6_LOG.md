# v1.1.1 local preview — Review 6

Status: **local test package only**. GitHub repository and published v1.0.0/v1.1.0 releases are unchanged.

## What changed

1. **Source inspector:** the button is a real `btn-circle` with osu!'s `btn-circle__content` and search icon, anchored to the Source row. It no longer uses an unrelated blue standalone style. The separate native pencil for editing metadata remains untouched.
2. **Beatmapset front-page Download:** removed the additional `+` dropdown from the Info/hero view entirely. The native Download action stays in place; extension options remain available on eligible discussion views. This avoids the repeated front-page button-width regression.
3. **Nearby-post previews:** first checks text already present in rendered discussion cards, then tries the post API with the exact discussion/post IDs; when a post is absent, it optionally falls back to discussion-list data. The warning and original confirmation checkbox are preserved. If unavailable, the UI explicitly says to open the discussion.
4. **Comment usergroup badges:** targets the actual `.comment__row--header` with `a.js-usercard[data-user-id]` (also supported in discussion post headings), consults public API group membership, and inserts BN/NAT/GMT/BSC badges without replacing native roles. Probation is displayed only when the API explicitly marks it. Caches lookups and caps concurrent requests.
5. **Disabled posting actions:** unavailable Note/Praise/Suggestion/Problem actions use neutral osu!-style disabled visuals and are no longer represented as enabled colourful buttons.
6. **My Discussions:** merged follow-up monitoring into a single activity-sorted My Discussions view. New local-checkpoint activity displays above previously seen discussions, separated by visible `NEW UPDATES` and `PREVIOUSLY SEEN` dividers. Current Mapset and Favourites tabs are removed, while internal mapset retrieval remains available to the related-discussions checker.
7. **Draft recovery:** a short explanation describes when drafts save, how to restore one, and that restoration never posts anything. Indicates when the saved copy matches the current editor and provides a confirmation-protected Delete saved copy action.
8. **File uploads:** supports drag/drop and clipboard files, not only images, subject to a conservative extension allowlist and the existing 20 MB limit. Images insert `![name](url)`; documents, archives, osu!/osz and media insert `[name](url)`. Blocked executables and unsupported files show an explanation; upload success/failure remains visible. The s-ul.eu account/API key is still required, and availability of any particular file type is controlled by the hosting service.
