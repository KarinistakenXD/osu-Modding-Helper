# osu! Modding Helper v1.1.1 — Review 5 local verification

Status: **Local preview / not published / no GitHub commits made**

## Changes completed

1. **Nearby timestamp context**
   - Kept osu!web's native warning and duplicate-confirmation checkbox intact.
   - Added a compact, scroll-bounded list of nearby discussions using the native discussion URLs.
   - Timestamps link to `osu://edit/HH:MM:ms` via the official `beatmap-discussion-timestamp-decoration` class.
   - Each entry also retains an osu!web discussion link and, where API access permits, a short excerpt.
   - The first three visible entries request excerpts automatically; additional entries load on hover/focus.
   - Fixed a regression discovered in the test fixture where generated links duplicated the list.

2. **Ranking Criteria selection**
   - Kept semantic name mapping: Beginner/Easy, Normal, Advanced/Hard, Hyper/Insane, Expert/Extra.
   - For relative labels like **Top**, uses SR as a *tentative* suggestion and explicitly states that Top is not a formal RC class.
   - Maintains manual RC-tier override and hides difficulty controls for general RC topics.

3. **Native editor and toolbar**
   - Coach and Settings use the site's `btn-osu-big` family with blue backgrounds and white labels.
   - Disabled Note/Praise/Suggestion/Problem and metadata Copy buttons are visually neutral rather than brightly coloured.
   - Settings / Coach have consistent button heights and wrap on narrow viewports.
   - Source inspector has greater separation from osu!'s edit-pencil control; native Download remains the primary action.

4. **Discussion roles**
   - Supports official public BN, NAT, GMT and BSC group data when returned by osu!'s API.
   - Shows `BN · probation` only when the public BN group explicitly has `is_probationary: true`.
   - Does not guess a user's privileges from usernames or avatars and avoids duplicating native group badges.

5. **Coach positioning**
   - Coach remains logically open while typing.
   - It becomes visually hidden when its editor's toolbar scrolls outside the useful viewport and reappears when near the toolbar again.
   - It still closes via the Coach button or its own Close control.

6. **Drag-and-drop and image pasting**
   - Shows a dimmed, full-screen `Drop an image to upload` overlay when an image file is dragged over a discussion page.
   - Uploads to the focused editor via the configured s-ul.eu key without navigating away.
   - Includes loading/success/failure status and keeps Ctrl+V paste support.
   - Dropping without an active editor produces feedback instead of silently replacing the browser page.
   - Added a fallback upload-placeholder identifier for environments lacking `crypto.randomUUID()`.
